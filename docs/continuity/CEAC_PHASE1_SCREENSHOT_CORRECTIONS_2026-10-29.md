## Changed contracts

Forward migration `20261029112823_work_activity_evidence_followup_and_edit.sql` was generated by Supabase CLI 2.117.0. It extends existing private file contexts without changing unrelated context permissions; only the activity contributor may attach evidence. Read access inherits the activity's work visibility and private/confidential contributor restrictions. Existing activity rows stay append-only.

`plan_work_activity_followup(uuid)` checks active account, organisation, assurance, underlying work visibility and contribution ownership. One activity creates at most one private Calendar task under a row lock. The task keeps its date and original work link and survives assignment completion. Deleting the private task does not silently recreate it. Corrections do not automatically replace existing private plans.

`edit_open_work_details(...)` checks creator or actual assigning-manager authority, current organisation/membership/visibility, open status and last movement timestamp. It changes title/brief fields only. Exact before/after details are retained in a private revision table; the broader activity feed receives no copied private content. No assignment, review authority or completion change is made.

The two new RPC signatures are explicitly inventoried by the authenticated-definer security gate (176 versus the previous 174). The reviewed historical migration inventory remains unchanged; the new migration is separately enumerated (212 total).
