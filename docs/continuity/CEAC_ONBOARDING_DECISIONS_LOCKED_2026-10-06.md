# CEAC onboarding decisions locked — 6 October 2026

Authority: explicit product-owner instruction, 6 October 2026. These decisions guide the Onboarding, Access & Presence Foundation tranche. Newer accepted canonical work is reconciled forward. Employment roster identity remains independent of login identity; no duplicate employee or fabricated email is permitted.

1. One person / one account / multiple unit memberships.
2. Admin may invite ordinary Staff into any authorised active CEAC unit.
3. Managers may invite ordinary Staff only inside managed units.
4. Adding an existing person to another unit is membership assignment, not another invitation.
5. Control Center → People & Access becomes the primary administrative surface for onboarding/access administration.
6. Volunteer does not create a new panel; volunteer uses Staff experience, with sub-team-lead capability possible.
7. Shared passwords are rejected.
8. Staff activation must not expose Vercel account authentication.
9. Office Start Work requiring location must not silently proceed with null location.
10. Start evidence records location + accuracy/geofence context where available.
11. End Work attempts fresh location but remains closable if location cannot be obtained.
12. No continuous background GPS tracking.
13. Location verification and app activity are separate facts.
14. Manager review authority sees Approve / Return, not Send for review.
15. New/action-required work needs explicit unread/action visibility.
16. Compliance is both a unit and an organisation-wide capability/function.
17. No compliance salary deduction automation.
18. No final scoring model yet.
19. Presence ≠ productivity.
20. Hours ≠ payroll automatically.

Confirmed refinements:
- Admin access operations retain explicit people.manage / authority.manage boundaries. Job titles and selected-unit context never grant organisation capabilities.
- Managers cannot assign Unit Heads, transfer across units, grant organisation capabilities or deactivate unrelated users.
- Office start evidence must include device and server time. End location failure must be attributable without trapping the session open.
- Private off-site location stays attached to authorised session evidence.
- Volunteers are not automatically payroll employees or Unit Managers.
- Compliance is an organisational unit plus explicit organisation-wide capability, not a fifth role panel.
- Existing private/agreed work, manager-owned work, self-certification and review history remain protected.

These decisions do not authorize the deferred policy engines listed in the next-build document.
